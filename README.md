# ✅ To-Do List App

A simple and responsive To-Do List application to manage your daily tasks efficiently.

**Live Demo:** https://koda-bhavani.github.io/todo-list-app/

### ✨ Features
- ➕ Add new tasks
- ✏️ Edit tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 💾 Saves tasks in Local Storage (won't delete on refresh)
- 📱 Fully Responsive - Mobile & Desktop
- 🎨 Clean & Minimal UI

### 🛠️ Built With
- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
- **Local Storage** for data persistence
- **GitHub Pages**

### 📁 Files
todo-list-app/
├── index.html   
├── style.css   
├── script.js    
└── README.md

### 🚀 How It Works
1. Type your task in input box
2. Click Add to add to list
3. Click on task to mark as complete
4. Edit or Delete with buttons
5. Data is saved automatically in browser
